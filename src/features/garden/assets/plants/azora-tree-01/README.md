# Azora Tree 01

Five AI-generated growth stages for the garden prototype:

- `seed.png`
- `sprout.png`
- `sapling.png`
- `young.png`
- `mature.png`

All production files are 1254 x 1254 RGBA PNGs with transparent corners. The
root or seed is centered on a shared lower-canvas anchor so stages can be
crossfaded and scaled from the soil position.

The `source/` directory retains the original chroma-key generations.

## Generation direction

Use case: stylized-concept. Cozy adult-wellness mobile-game tree with softly
painted vector-like forms, eucalyptus and deep-teal foliage, warm cocoa and
terracotta soil, gentle upper-left light, and a restrained magical quality.
Stages were derived sequentially from the same visual reference. Backgrounds
were generated as flat magenta chroma key and removed locally with the Codex
image-generation skill's soft-matte and despill helper.

Generated with the built-in image generation tool on 2026-08-04.
