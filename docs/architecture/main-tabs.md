# Main tabs

- **Home** owns the mascot, room, guided daily activities, and room reward flow. Its activity list has no personal to-dos or habit creation action.
- **Routine** (internal route `Plan`, screen title “My Routine”) shows the weekly activity calendar and personal to-dos. It owns task creation, editing, completion, and completion feedback (haptics and toast). Its task list does not rewrite Home’s activity order.
- **Reset** (internal route `Reset`) provides the exercise library.
- **Explore** provides curated routine ideas and read-only practical resources. It does not automatically add to-dos to a personal routine.
- **Your Plan** (internal route `Insights`) combines profile identity editing, room history access, the consistency calendar, Azora score, mood and activity insights, program weeks, and program start/finished states.

Profile content lives directly in Your Plan; there is no separate Profile route. Existing avatar and streak shortcuts select it. Settings and detailed History remain secondary screens reached from it.

Home’s activity-list completion reflects guided activities only. The existing room reward rule still counts both guided activities and personal to-dos.
